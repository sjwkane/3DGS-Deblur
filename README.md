# 3DGS-Deblur
# 我在研究如何从多视角模糊照片重建清晰的三维场景，并从新的相机位置渲染图像。目前以 DeepDeblurRF 的 3DGS 版本为基线，关注其中一个环节：三维场景给二维去模糊网络提供什么信息，才能让下一轮重建更准确？
# 我已在 BlurRF-Synth 的运动模糊场景 `cozyroom` 上跑完五轮重建。A 组第 5 轮在 5 个测试视角上的平均 PSNR 为 30.13 dB，SSIM 为 0.8853。仓库中已有 7 篇泛读笔记；下面的指标来自基线复现，多视角引导方案目前只做了局部图像对照。

## 二、为什么保留 DeepDeblurRF 的清晰图监督？

DeepDeblurRF 在第一轮先做单图去模糊。建出初始场景后，后续各轮沿着这条路径更新：

**本视角原始模糊图 + 当前场景在本视角的渲染图 → 引导去模糊网络 → 本轮恢复图 → 用各视角恢复图监督下一轮 3DGS。**

我最初考虑把前三篇论文的“合成模糊图算损失”直接接进来。这里要分清两张图各自的用途：在 BAD-Gaussians 等方法中，合成模糊图用来检验当前场景能否解释真实曝光；在 DeepDeblurRF 中，去模糊网络输出的恢复图用来告诉下一轮 3DGS 应该拟合哪些清晰细节。如果把恢复图直接换成模糊图，再让普通 3DGS 拟合整张模糊图，刚恢复出的边缘就失去了这条监督。因此，我目前想**保留恢复图作为重建目标，优先研究怎样改进引导图**。若额外增加一个再模糊分支，让它与原始观测计算辅助损失，两种监督在原理上可以共存。

## 三、从 SelfHVD 引出的两个想法

### 想法 1：能否用其他照片的清晰局部，训练单图去模糊网络？

读 SelfHVD 时，我想到：如果视频里相邻帧可以互相提供清晰细节，那么恢复一张模糊照片时，能否从其他实拍照片里借到同一处的清晰纹理？难点是照片之间的视角跨度可能更大，同一物体可能移位、被遮挡，或者在每张照片里都模糊。

随后读到的 **BluRef** 已经直接研究了这个问题。它在训练中用当前恢复结果定位要匹配的内容（首次匹配从原始模糊图开始），把参考照片的可靠细节搬到目标坐标，合成伪清晰图，再用置信掩码筛选监督区域。训练好的网络在测试时可以只输入一张模糊图。因此，这条思路与已有工作重合较多。我从中保留了一个值得迁移的问题：**当参考图的来源改变时，匹配成功的纹理是否仍然可信？**

### 想法 2：能否给 DeepDeblurRF 加入邻近机位的渲染引导？

假设正在恢复视角 A。我想保留 A 的原始模糊图和本机位渲染，同时让同一个 3DGS 从邻近机位 B、C 渲染，再把其中与 A 对应的局部特征对齐回来。例如，A 图里钟面的刻度很淡，如果 B 图把同一条刻度渲染得更清楚，并且能准确放回 A 的位置，B 才提供了额外的信息。这个设想借鉴了 SelfHVD 的跨帧互补和 BluRef 的稠密匹配，但参考来源变成了**当前三维场景自身的渲染**。

| 相关工作 | 恢复视角 A 时，其他视角的信息怎样传回来？ |
| --- | --- |
| **ReSplat**（已泛读） | 三维侧返回高斯中心的位置，恢复网络在下一扩散步利用这些位置对齐并融合不同输入视角的特征，再预测残差。 |
| **CasDeblurGS**（已了解方法导读，原文待核对） | 第一阶段把另一张输入照片初步处理后，对齐到 A 并用掩码筛选；第二阶段用两张中间恢复图建临时三维场景，把 **A 原始模糊图 + 临时场景在 A 机位的渲染图**交给恢复网络。 |
| **我想验证的改动** | 在引导端把**邻近机位的渲染结果**也作为独立候选。要验证的是：本机位渲染已经融合了多视角信息，再引入对齐后的邻机位渲染，究竟还能补回哪些细节？ |

## 四、目前观察到了什么？

我用 `cozyroom` 的已有结果做了初步检查。以第 3 轮的测试视角 `024` 为例，选取表盘、书脊、盆栽和窗框等局部，从同一轮保存的 `016`、`032` 渲染图中寻找对应区域。目标机位的评测参考图仅用于事后比较。

在检查的表盘区域，本机位渲染中的刻度很淡，邻机位对齐后也没有明显补出刻度。但这次采用的是**局部平面近似对齐**；即使把邻机位渲染换成数据集的参考照片，同样的对齐也会产生明显误差。因此，这次观察还分不清“邻视角确实缺少细节”和“细节存在，但没有对准”。目前尚未修改去模糊网络或训练新模型。若继续这个方向，我会先验证对齐能否可靠地搬回已知存在的细节，再决定是否改网络。
